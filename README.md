## 📌 Sobre o Projeto

O **Quicklist** é um projeto prático desenvolvido como parte dos desafios de **JavaScript** da plataforma **Rocketseat**. 

O objetivo principal da aplicação é aplicar e consolidar conceitos fundamentais de desenvolvimento web *Front-End*, englobando desde a estruturação semântica da página até a manipulação dinâmica do DOM (*Document Object Model*) e tratamento de eventos do usuário.

---

## ✨ Funcionalidades

- ➕ **Adicionar Itens:** Digite o nome do produto no campo de entrada para adicioná-lo dinamicamente à lista.
- ☑️ **Marcar como Concluído:** Selecione a *checkbox* para indicar que o item já foi comprado.
- 🗑️ **Remover Itens:** Exclua produtos da lista com um simples clique no ícone de lixeira.
- ⚠️ **Alerta Dinâmico:** Notificação visual informando que o item foi removido com sucesso, com opção de fechar a mensagem.
- 📱 **Interface Responsiva:** Layout adaptado para boa usabilidade em dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído do zero sem dependência de bibliotecas externas ou *frameworks*, utilizando o ecossistema nativo da Web:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização moderna, variáveis CSS, layout flexível (Flexbox/Grid) e animações leves.
- **JavaScript (Vanilla):** Manipulação de elementos do DOM, captura de eventos e lógica do formulário.
